# LZL · PERSONAL TERMINAL

明日方舟官网（ak.hypergryph.com）风格的科技感个人主页 + 博客。
深色 HUD 底盘、切角面板、网格与扫描线、白字 + 凯尔希绿，毛玻璃保留。
背景是 `wallpaper.mp4`（4K60 动态壁纸，角色：明日方舟 · 凯尔希）。

零依赖、零构建：双击 `index.html` 就能跑。

---

## 一、怎么打开

**方式 A：直接双击**

打开 `index.html`。全部功能在 `file://` 下正常（没有用 `fetch`，数据以 JS 变量内联）。

**方式 B：本地起服务**（推荐，视频加载与缓存表现更接近线上）

```bash
cd lzl-blog
python3 -m http.server 8901
# 浏览器打开 http://127.0.0.1:8901
```

**方式 C：部署**

整个 `lzl-blog/` 目录原样上传即可（GitHub Pages / Vercel / Netlify / 任意静态托管）。
没有构建步骤，不需要 Node。

> 当前已按 **28 考研**（2028 年入学 → 初试 2027 年 12 月）配置好，进度按你提供的真实情况填了：
> 高数一半、数据结构一半、英语单词 60%，其余未开始。总进度约 **20%**。

### 进度怎么写：按模块，不按科目

不要手填「数学二 40%」这种笼统数字——它没法表达「高数做了一半、线代还没碰」。
改成给每个**模块**填完成度 `p`，科目和总进度会自动按权重算出来：

```js
subjects: [
  {
    code: "302", name: "数学（二）", score: 150,   // score = 该科满分，用于总进度加权
    modules: [
      { name: "高等数学", w: 78, p: 50 },          // w = 相对权重，p = 完成度 0-100
      { name: "线性代数", w: 22, p: 0  }
    ]
  },
  // ...
]
```

- **科目进度** = 该科各模块按 `w` 加权平均。上面这科 → (78×50 + 22×0) ÷ 100 = **39%**
- **总进度** = 四科按 `score`（100/100/150/150）加权平均 → 当前 **20%**
- `w` 不需要加起来等于 100，代码会按总和归一化

**你只需要改 `p`**（和需要时加模块）。学到哪就改哪，其余不用动。

### 里程碑三态

```js
milestones: [
  { time: "2026.09 – 2027.02", text: "基础阶段：…", state: "active" },  // done / active / todo
]
```

`active` 的那条会高亮并带「进行中」徽章、图标带呼吸光效。当前是基础阶段。

### 考试日期

由 `enrollYear` 与 `examYear` 决定：

```js
enrollYear: 2028,   // 28 考研 = 2028 年入学
examYear: 2027,     // → 初试在 2027 年 12 月
```

页面自动取 `examYear` 年 12 月的**第三个周六**（近年初试都在这一天，2027 年即 12 月 18 日）。
教育部公布确切日期后，在 `examDateOverride` 里写死即可，例如 `"2027-12-18"`。

> 读研年份是按**入学年**命名的：28 考研 = 2027 年 12 月初试、2028 年 9 月入学。别和「考试那年」混了。

## 四、换背景视频 / 头像

```
assets/video/wallpaper.mp4   ← 已从 4K 原片转码（20MB → 3.0MB，1920×1080，无音轨）
assets/img/poster.jpg/.webp  ← 视频首帧海报，用于不支持视频时的兜底
assets/img/avatar.jpg/.webp  ← 从头像裁出的脸部特写
```

**换视频**（保持文件名不变即可）：

```bash
ffmpeg -i 你的视频.mp4 -vf "scale=1920:-2:flags=lanczos" \
  -c:v libx264 -profile:v high -preset medium -crf 26 \
  -pix_fmt yuv420p -movflags +faststart -an \
  assets/video/wallpaper.mp4
ffmpeg -y -ss 9 -i 你的视频.mp4 -frames:v 1 -vf scale=1920:-2 /tmp/poster.png
# 再把 /tmp/poster.png 另存为 assets/img/poster.jpg 和 poster.webp
```

**换头像**：`avatar.jpg` / `avatar.webp` 是从视频第 9 秒的 4K 帧里按（脸部中心 x≈61.7%）裁的正方形。
裁切焦点在 `style.css` 的 `.idcard__av img { object-position: 52% 22% }`。

> 如果新视频里人物位置不同，同步调整 `.bgv__media` 的 `object-position`（现在是 `center 38%`）。

## 七、设计说明

### 明日方舟风格的几个关键手法

- **切角面板**：`clip-path: polygon(...)` 切掉左上/右下角；描边用「外壳 padding:1px + 内层同形状」实现，保证切角处的边线连续
- **HUD 描边**：`inset box-shadow` 画细边框，配合切角形成刻意的断线
- **观测角标**：`.cell` 悬停时四角出现小直角线（`::before/::after`）
- **技术标注**：`01 / PROFILE` 式区段头、`// IDENTITY RECORD` 注释、等宽字体小标签
- **网格 + 扫描线 + 噪点**：三层固定装饰（`.fx` / `.fx::after` / `.grain`），外加一条缓慢下移的扫掠光带
- **大字号压缩体**：`Saira Condensed` 做标题与数字

### 配色

| 变量 | 深色 | 白昼 | 用途 |
| --- | --- | --- | --- |
| `--acc` | `#7BE5B4` | `#1E8E5E` | 凯尔希绿 · 强调色 |
| `--ink` | `#EDF7F1` | `#0E1F18` | 主文字（暖白 / 深墨绿） |
| `--base` | `#04080a` | `#eef4f0` | 底盘 |
| `--glass` | `rgba(5,14,12,.56)` | `rgba(255,255,255,.62)` | 毛玻璃填充 |

想整体换色，只改 `style.css` 顶部 `:root` 与 `[data-theme="light"]` 里的令牌，全站自动跟随。

## 八、已知取舍与踩坑记录

### 两个真实修掉的坑（都会复现，改代码时别踩回去）

**1. `html,body{height:100%}` 会让暗纱只剩一屏高**

`.scrim`（内容暗纱）用的是 `position:absolute; inset:0`。如果 `body` 被 `height:100%` 锁死在视口高度，`inset:0` 的参照盒就只有一屏——**滚过第一屏之后暗纱根本不存在**，正文直接压在壁纸最亮的地方，全部糊掉。

正确写法：

```css
html{ height:100% }
body{ min-height:100% }   /* 不是 height */
```

**2. 深色毛玻璃不能是「亮玻璃」**

第一版 `--glass` 用了 `rgba(178,255,224,.055)`（很淡的绿白）。壁纸高光区接近纯白，淡玻璃压上去等于没有，浅色文字直接被背景吃掉。
深色主题的玻璃必须**自带暗底**（`rgba(5,14,12,.56)`），再靠 `backdrop-filter` 透出模糊后的背景。这也是"毛玻璃"在亮背景上的唯一可靠做法。

### 其他取舍

- **SEO 偏弱**：日志由 JS 渲染，爬虫需执行 JS。个人站点用「三年后还能双击打开」换的。
- **留言板不是真留言板**：仅存本地。想做成真的，接 Giscus / Waline 替换 `post.html` 里的 `#comments` 区块。
- **视频体积**：3.0MB / 1080p。想更小就把 `scale=1920:-2` 改成 `-2:1280` 并调高 `crf`；也可以再导一份 WebM(VP9) 做双源。
- **移动端**：小屏自动隐藏左侧导轨和首屏右侧信息卡，导航收进汉堡菜单。
- **`prefers-reduced-motion`**：会关闭视频、扫掠、噪点与全部入场动画——这是有意的，不只是省电。
